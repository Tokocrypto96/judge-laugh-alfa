## How it works

`main.py` (Python standard library only, no network, no secrets) writes the
joke to `/output/entry.txt` — a single line, 87 characters, well under the
200-character gate. The output is fully deterministic: run it twice, get the
same bytes.

```sh
python3 main.py            # writes /output/entry.txt
```
